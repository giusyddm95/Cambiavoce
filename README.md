# Cambiavoce

App web per trasformare la voce in tempo reale dal microfono del telefono (uomo, donna, bambino, anziano, mostro, fantasma, corvo e altre, 33 voci in tutto).

Aprila da https://giusyddm95.github.io/Cambiavoce/ e usa "Aggiungi a schermata Home" per installarla.

Per sentirti dal vivo servono le cuffie, meglio col filo. Per preparare frasi da far sentire ad altri usa Registra: registra la voce così com'è, applica la voce scelta dopo (si può cambiare anche a registrazione finita) e con "Salva o condividi" tieni il file.
